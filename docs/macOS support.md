# macOS support

## Brief

Actualmente no dispongo de un equipo con macOS, por lo que no puedo probar ni mantener de forma
fiable las instrucciones específicas para este sistema operativo.

La configuración está desarrollada y probada principalmente en Linux y Windows. Por este motivo,
las secciones relacionadas con macOS pueden estar incompletas, desactualizadas o contener
instrucciones que requieran ajustes adicionales.

Si utilizas macOS y encuentras algún problema, agradeceré especialmente cualquier _issue_, _pull
request_ o corrección que ayude a mantener esta parte de la documentación.

Si necesitas soporte para macOS con urgencia, también puedes contribuir mediante [Donar](https://www.paypal.com/donate/?hosted_button_id=W9K3ZTUM2QNAC). Las
donaciones se destinarían a disponer temporalmente de un entorno macOS con interfaz gráfica para
poder probar, corregir y completar estas secciones de forma adecuada.

Mientras no disponga de un entorno de pruebas apropiado, la compatibilidad con macOS debe
considerarse **experimental y no garantizada**.
